Definition I.1 · Natural Transformation

Commuting Squares Between Functors

Let F, G : C → D be functors. A natural transformation α : F ⇒ G assigns to each object X ∈ C a component αX : F(X) → G(X) such that for every f : X → Y:

G(f) ∘ αX = αY ∘ F(f)

  app : ∀ X : C, F.obj X ⟶ G.obj X
  naturality : ∀ {X Y : C} (f : X ⟶ Y),
    F.map f ≫ app Y = app X ≫ G.map f

  obj X   := A ⟶ X
  map f g := g ≫ f

Subslip II.1a · Element Chasing

Why α Is Uniquely Determined by αA(idA)

Set X = A and evaluate naturality at f : A → Y applied to the universal element idA ∈ HomC(A, A):

αY(f) = αY(f ∘ idA) = (αY ∘ Hom(A, f))(idA) = F(f)(αA(idA))

def yoneda_fwd (α : NatTrans (Hom A) F) : F.obj A := α.app A (𝟙 A)
def yoneda_bwd (u : F.obj A) : NatTrans (Hom A) F := {
  app := fun _ f => F.map f u,
  naturality := fun g => by funext f; exact F.map_comp f g u
}
theorem yoneda_left_inv (α : NatTrans (Hom A) F) :
    yoneda_bwd (yoneda_fwd α) = α := by
  apply NatTrans.ext; funext Y f
  have h := congrFun (α.naturality f) (𝟙 A)
  rw [Category.id_comp] at h
  exact h.symm

def yonedaEquiv {C : Type*} [Category C] (A : C) (F : C ⥤ Type*) :
    (coyoneda.obj (op A) ⟶ F) ≃ F.obj A where
  toFun α := α.app A (𝟙 A)
  invFun u := {
    app := fun Y f => F.map f u
    naturality := by intro X Y g; ext f; simp [Functor.map_comp]
  }
  left_inv α := by
    ext Y f
    dsimp [yonedaEquiv]
    have h := α.naturality f
    simpa using congrFun h (𝟙 A)
  right_inv u := by simp

Corollary III.1 · Full Faithfulness

The Yoneda Embedding & Full Proof Architecture

Instantiating F := HomC(B, −) in Theorem II.1 yields a canonical bijection between morphisms in C and natural transformations between representable functors:

HomC(B, A) ≅ Nat(HomC(A, −), HomC(B, −))

Hence the contravariant Yoneda embedding よ : Cop ⥤ (C ⥤ Type) is fully faithful: two objects A, B ∈ C are isomorphic if and only if their representable functors are naturally isomorphic.
